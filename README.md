# Guess The Number v 1.1.1

My first Python game.

## Features:
- 3 difficulty levels
- Attempts system
- Statistics
- Save/load system
- Best score

## Requirements:
- Python 3.15

## How to run:

1. Download the project.
2. Open the project folder in VS Code.
3. Run `main.py`.

The game will automatically create save files:
- `stats.txt`
- `record.txt`

## Controls:
- Choose difficulty: 1 / 2 / 3
- Guess the number
- Play again: y / n
